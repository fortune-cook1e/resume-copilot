# Kakuna and Scizor templates

Add [Kakuna](https://rxresu.me/templates/pdf/kakuna.pdf) and [Scizor](https://rxresu.me/templates/pdf/scizor.pdf) to Design → Template. Kakuna centers the identity, contacts, and section headings and uses the theme color for the heading rule. Scizor adds an accent rule to every page, a gray rule below the name, and uppercase section headings above the section content.

The template cards use static thumbnails. Selecting a card previews the current resume and saves the template with the draft. Keep the resume content, section order, page settings, typography, density, and theme color. Onyx remains the default. Preview and download use the same PDF, and the compatibility print page uses the same template styles.

Use one authenticated browser journey with a two-page resume to check switching, save and reload, explicit page breaks, wrapped text, and downloaded PDFs for both templates. Two-column layouts and live thumbnail generation are outside this slice.
