- One NestJS auth/runtime only. `plugins/resume-copilot/plugin.json` and `mcp.json` plus `.agents/plugins/marketplace.json` distribute the loopback Streamable HTTP endpoint. Agent Plugins 1.0.0 schemas, catalog mapping, identity and endpoint passed static checks using local Ajv. On 2026-09-26 the user confirmed installation and a Codex `get_connection_status` call. - CIMD securely resolves allowlisted ChatGPT-hosted metadata with public-DNS/TLS checks and no redirects; open DCR is disabled. `/oauth/consent` displays the signed-in account/permission and preserves the signed interaction through Google sign-in. Consent/PKCE grants access for at most 15 minutes and a connection for an absolute 30 days. OAuth repository/service own persisted state; the original consent timestamp survives delayed exchange and refresh, never resets. A request-scoped reference becomes a signed JWT claim; signature/issuer/audience/scope plus owner/client/scopes/expiry/revocation are checked. No browser-session FK or connection-state cache; valid JWTs cannot outlive the connection. Internal owner-scoped revocation exists, but no authenticated management/revocation endpoint or UI.
